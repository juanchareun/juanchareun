## 🔒 About Me

I'm a **Cybersecurity Support Engineer at ThreatLocker** focused on **endpoint security, identity, networking, and cloud technologies**.

I work with enterprise security solutions involving **application control, zero trust network access (ZTNA), SIEM integrations, APIs, Linux environments, Active Directory, and troubleshooting complex customer infrastructures**.

Currently, I'm expanding into **DevOps and DevSecOps**, building hands-on experience with **Linux, Git, Docker, CI/CD pipelines, Jenkins, cloud platforms, and infrastructure automation** through personal labs and real-world projects.

I document my learning journey through homelabs, security research, and infrastructure projects to continuously improve my technical skills.
